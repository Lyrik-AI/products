## Repository layout

| Path | Contents |
|---|---|
| `tours/<slug>.md` | One page per multi-day tour (slug matches `lyriktrip.com/tours/<slug>`) |
| `experiences/<slug>.md` | One page per day experience (slug matches `lyriktrip.com/experience/<slug>`) |
| `data/products.json` | Structured index of every product (title, duration, price, cities, themes, cover, URLs) |
| `llms.txt` | Machine-readable index for AI assistants |

Every page starts with YAML front matter (`title`, `seo_title`, `tagline`, `duration`, `days`, `price_from_usd`, `cities`, `themes`, `cover`, `official_url`, …), so the files can be loaded directly as an Astro / Next.js / MDX content collection.

Prices are "from" prices in USD per person; live prices, dates and booking are on the official page of each product.
